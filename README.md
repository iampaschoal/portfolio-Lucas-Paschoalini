# Portfólio de Lucas Caiaffa Paschoalini

Site estático em HTML, CSS e JavaScript, sem etapa de compilação.

## Publicar no GitHub Pages
1. Extraia o ZIP e abra a pasta `portfolio-lucas`.
2. Crie um repositório no GitHub (por exemplo, `portfolio-lucas`).
3. Envie **o conteúdo dessa pasta**: `index.html`, `assets`, `.nojekyll` e este README devem ficar na raiz do repositório.
4. Em **Settings → Pages**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.
5. Aguarde a publicação. Se publicado na conta informada, o endereço será `https://iampaschoal.github.io/portfolio-lucas/`.

## Estrutura
- `index.html`: conteúdo e links.
- `assets/css/style.css`: estilos responsivos, temas e animações.
- `assets/js/main.js`: menu móvel, tema persistente, navegação ativa e animações.
- `assets/img/lucas.jpeg`: foto original enviada.
- `assets/img/favicon.svg`: ícone do site.
- `assets/docs/curriculo-lucas-paschoalini.pdf`: currículo original enviado, disponível para download.

## Editar
Altere os textos e contatos diretamente no `index.html`. Para substituir a foto ou o currículo, mantenha os nomes dos arquivos acima ou atualize os links no HTML.

Os dados profissionais e contatos foram extraídos do currículo fornecido. O GitHub foi informado pelo solicitante. O projeto de startup é descrito sem nome comercial ou link de repositório, pois esses dados não constam no currículo. Não foram criadas experiências, métricas ou datas adicionais. As fontes Google são opcionais: o site usa fontes locais de reserva quando estiver offline. Não há formulário ou backend; os contatos abrem os serviços correspondentes.
